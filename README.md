## Overview

This repository contains lab work for LAB 3 of the Computer Fundamentals & Career Pathways (CSE103) course at K.R. Mangalam University, Gurugram.

The objective of this lab is to learn GitHub collaboration, version control, meaningful commits, remote repositories, API interaction and Markdown documentation.
